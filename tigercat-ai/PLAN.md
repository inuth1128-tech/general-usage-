## 1. 회사 구조

```
CEO (나)
 └─ 비서실장 "한비서"  ← 나는 이 분에게만 지시한다
      ├─ 기획팀장  "기획이"  : 채널 콘셉트, 주제 발굴, 콘텐츠 캘린더
      ├─ 작가      "글이"    : 쇼츠/릴스 대본, 제목, 설명, 해시태그
      ├─ 디자이너  "그림이"  : 이미지·썸네일 생성 (Google Gemini)
      ├─ 영상편집  "편집이"  : 이미지+음성+자막 → 쇼츠/릴스 영상 조립
      ├─ SNS 담당  "쓰레드"  : Threads 글, 인스타 캡션, 업로드 준비, 반응 분석
      ├─ 브랜드사이트 담당 "웹이" : tigercat-ai 브랜드 사이트(채널 허브)
      └─ 검수담당  "꼼꼼이"  : 최종 검수 (사실, 오탈자, 저작권, 플랫폼 정책)
```

### 업무 흐름
1. CEO → 비서실장에게 지시 (업무사이트)
2. 비서실장이 담당자 **회의 소집** (메신저 회의방)
3. 담당자 토론 → 비서실장이 **회의록 정리** → 업무 배정
4. 담당자 수행 → 검수 → 비서실장 최종검수 → CEO 보고
5. **업로드는 CEO 승인 버튼을 눌러야만** 진행

### 쇼츠/릴스 제작 파이프라인
```
주제 선정 → 대본 → 장면별 이미지(Gemini) → 음성(TTS) → 자막
   → 영상 조립(ffmpeg, 9:16) 또는 Higgsfield 영상 생성 → 검수 → CEO 승인 → YouTube / Instagram / Threads
```
- 기본 방식(저비용): Higgsfield 이미지 + 음성 + 자막을 ffmpeg로 조립
- 고품질 방식: **Higgsfield 영상 생성(Seedance 등)** — 크레딧을 쓰므로 **스토리보드 이미지 승인 → 크레딧 견적 → 대표 승인** 후에만 생성
- Higgsfield에 쇼츠/설명영상용 작업 흐름이 있어 활용 가능 (9:16 쇼츠 등)

## 3. 기술 구성

| 영역 | 선택 | 이유 |
|------|------|------|
| 런타임 | Node.js (TypeScript) | 이미 설치됨 |
| DB | **SQLite** | 설치 불필요, 직원/업무/기억 저장에 충분 |
| 사이트 | React(Vite) + Node API | 이 저장소와 동일 구성 |
| 메신저 | WebSocket | 실시간 대화 |
| 두뇌 | **Claude Code (터미널 호출)** | Pro 구독 안에서 사용 |
| 이미지/영상/음성 | **Higgsfield MCP** (보조: Google Gemini API) | 연동 완료, 크레딧 보유 |
| 영상 조립 | ffmpeg | 무료, 로컬 실행 |
| 버전관리 | git + GitHub | 설치됨 |

### Claude Pro 한도 관리 (중요)
Pro는 사용량 한도가 있어서 직원 여럿이 길게 토론하면 금방 소진됩니다. 그래서:
- 직원 호출은 **순차 실행**, 회의는 **1~2라운드로 제한**
- 업무당 호출 횟수 상한, 대시보드에 **오늘 사용량** 표시
- 단순 작업(자막 분할 등)은 Claude 없이 **일반 프로그램**으로 처리
- 한도 임박 시 **작업 일시정지 → 저장 → 다음에 이어서**

## 5. 대표님 준비물 (하나씩 안내)

이미 있음: Node.js, git, GitHub

1. 터미널(PowerShell) 여는 법
2. 설치 확인: `node -v`, `git --version`
3. 이 저장소 내려받기 (`git clone`)
4. **Claude Code 로그인 확인** (Pro 구독)
5. **내 컴퓨터의 Claude Code에도 Higgsfield MCP 연결** (지금 연동은 이 클라우드 세션 기준이라 로컬에서도 한 번 연결 필요 — 방법 안내)
5-1. (보조) Google AI Studio Gemini API 키 발급 → `.env` 파일에 보관
6. **ffmpeg 설치** (영상 조립용)
7. **채널 4개 신규 개설** (순서대로 안내): Google 계정 → YouTube 채널 / Facebook 계정+페이지 → Instagram 프로페셔널 계정(페이스북 페이지 연결) → Threads(인스타 계정으로 로그인). 같은 채널명·프로필 이미지로 통일
8. 9단계 때: YouTube(Google Cloud 프로젝트·OAuth), Meta 개발자 앱(Instagram·Threads) 연동 — 가장 복잡해서 화면 보며 안내
