자동 확인 설정 (YouTube)

API 키 받는 방법 (처음 한 번, 무료)
  1. console.cloud.google.com 에 YouTube 채널을 만든 구글 계정으로 로그인
  2. 위쪽 프로젝트 선택 → 새 프로젝트 만들기 (이름은 tigercat 아무거나)
  3. 왼쪽 메뉴 API 및 서비스 → 라이브러리 → YouTube Data API v3 검색 → 사용
  4. 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키
  5. 나온 키를 복사해서 위 칸에 붙여넣고 키 저장
키는 이 컴퓨터의 .env 파일에만 저장되고 GitHub에는 올라가지 않습니다. 하루 사용 한도(10,000)에 비해 이 확인은 거의 쓰지 않습니다.
