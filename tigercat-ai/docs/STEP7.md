# 7단계: 쇼츠 1편 — 영상 조립 방법 (Windows)

## 영상 만들기
PowerShell에서:
```
cd ~\tigercat\general-usage-
git pull origin claude/new-session-p1cwk0
cd tigercat-ai
npm run short1
```
1~2분 뒤 `완성: ...\media\out\short1\short1.mp4` 라고 나옵니다.

## 영상 위치 열어보기
```
explorer media\out\short1
```
`short1.mp4` 를 더블클릭하면 재생됩니다. (세로 9:16, 약 30초)

## 하는 일
1. 장면 이미지 5장과 Arthur 음성을 Higgsfield 서버에서 내려받음 (크레딧 0)
2. 음성을 4% 빠르게 해서 30초 안에 맞춤
3. 음성의 쉬는 구간으로 문장 경계를 찾아 자막 타이밍을 맞춤 (못 찾으면 단어 수로 추정)
4. 큰 영어 대문자 자막 (NEVER, START 만 빨강)
5. 장면 5장 + 음성 + 자막 → mp4

## 자주 있는 문제
- `ffmpeg를 찾을 수 없습니다` → PowerShell 창을 닫고 새로 열기
- 자막 글꼴이 이상함 → `$env:CAPTION_FONT="Arial"` 입력 후 다시 `npm run short1`
- 다시 만들 때는 같은 명령을 한 번 더 실행 (내려받은 파일은 재사용)
- 장면 이미지를 새로 만들었다면 `media\out\short1\assets` 폴더를 지우고 실행

## 동적인 버전 (추가 파일, 기존 영상은 그대로)
```
npm run short1d
```
`media\out\short1_dynamic\short1_dynamic.mp4` 가 새로 생깁니다. 기존 `short1.mp4` 는 건드리지 않습니다. (이미 받은 이미지·음성은 재사용하므로 `npm run short1` 을 먼저 했다면 바로 만들어집니다. 안 했어도 알아서 내려받습니다.)

- 장면마다 카메라 움직임: 서서히 확대 → 멀어짐 → 반전 장면에서 밀고 들어감 → 따라가며 이동 → 멀어지며 마무리
- 장면 전환 효과 (반전 장면은 원이 퍼지는 전환)
- 자막이 톡 튀어나오며 나타남
- 크레딧 0, 1~3분 소요

전환 종류는 `media/short1_dynamic.json` 의 `transitions` 로 바꿀 수 있습니다. (예: `["fade","circleopen","smoothleft","fade"]`)

## AI 영상 클립 버전 (캐릭터가 실제로 움직임)
```
npm run short1m
```
`media\out\short1_motion\short1_motion.mp4` 가 새로 생깁니다. (기존 두 파일은 그대로)

- 장면 5개를 Kling 3.0으로 만든 5초 클립으로 사용 (크레딧은 이미 사용됨, 이 명령은 0)
- 클립이 장면보다 짧으면 최대 1.5배까지 천천히 늘리고, 그래도 모자라면 마지막 화면을 잠시 멈춤
- 장면 전환 효과 + 자막 효과는 동적 버전과 동일
- 클립 주소는 `media/short1_motion.json` 의 `clips` 에 있음

### 장면별 속도 조절 (AI 영상 클립 버전)
`media/short1_motion.json` 의 `scenes` 에서 장면마다 정합니다.

| 항목 | 뜻 |
|------|----|
| `speed` | 재생 속도. 1 = 원래 속도, 1.5 = 1.5배 빠르게, 0.74 = 느리게 |
| `fill` | 속도를 올려 클립이 짧아졌을 때 남는 시간 채우기. `pingpong` = 앞뒤 왕복, `hold` = 마지막 화면 유지 |
| `pushIn` | 장면 내내 천천히 확대 (0.1 = 10%) |

현재 설정: 장면1 ×1.0 / 장면2 ×1.5(왕복) / 장면3 fit(새 10초 클립 전체를 장면 길이에 맞춤, 끝 화면이 장면 4 시작과 이어짐) / 장면4 ×0.74(기준) / 장면5 ×1.0
"장면 2를 조금 더 빠르게" 처럼 말씀하시면 숫자를 조정해 드립니다.

### 전환 효과 조절
`media/short1_motion.json` 의 `transitions`(종류)와 `transitionSeconds`(길이, 초)를 장면 사이마다 정합니다.
현재: 1→2 부드럽게 겹침 0.3초 / 2→3 부드럽게 겹침 0.6초 / 3→4 왼쪽으로 부드럽게 0.25초 / 4→5 겹침 0.3초

### 클립 길이
클립마다 실제 길이를 자동으로 재서 계산합니다. (5초, 10초 등 섞여 있어도 됨)
장면 3은 10초짜리 새 클립(`clips` 의 6번째)을 사용합니다.

### 화면 전환 시점을 음성과 따로 정하기
`media/short1_motion.json` 의 `sceneStarts` (초). 예: `[5.0, null, null, null]` = 장면 2를 5초에 시작.
자막 타이밍은 바뀌지 않습니다. 현재: 장면 1을 클립 전체 5초 동안 보여줌 (벽 두드리는 동작이 잘리지 않게).

`speed: "fit"` = 클립 전체가 장면 길이에 딱 맞게 재생됩니다. 장면 3 클립은 끝 화면을 장면 4 첫 화면과 맞춰 만들었기 때문에 이 설정이 필요합니다. (숫자로 바꾸면 클립 끝이 잘려 이어짐이 깨질 수 있음)
