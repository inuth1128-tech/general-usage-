# 계획 게시판 — 사용법

업무사이트(http://localhost:3001) 맨 위쪽에 있습니다.

## 최신 파일 받고 켜기
```
cd ~\tigercat\general-usage-
git pull origin claude/new-session-p1cwk0
cd tigercat-ai
npm start
```
브라우저에서 **Ctrl+F5**. (기존 데이터는 그대로이고, 게시판 칸과 첫 계획이 자동으로 추가됩니다.)

## 하는 일
- **계획 올리기**: 제목, 내용, 알림 시점을 정해 올립니다.
  - 영상 게시 완료 후 알림 / 날짜에 알림 / 알림 없이 보관
- **영상 게시 완료 표시**: 영상을 올린 뒤 이 버튼을 누르면, "게시 완료 후 알림"으로 대기 중이던 계획이 화면 맨 위 노란 칸에 **"지금 시작할 계획"** 으로 나타납니다.
- 날짜 알림은 그 날짜가 되면 사이트를 열 때 자동으로 노란 칸에 나타납니다.
- 노란 칸의 **"이 계획으로 회의 열기 준비"** 를 누르면 회의 주제 칸에 계획 내용이 채워집니다.
- 끝낸 계획은 **완료**, 필요 없으면 **삭제**.

## 처음 올려 둔 계획
"다음 영상: 만약 ~라면 시간 경과 형식 (레퍼런스: 달이 사라진다면)" — 첫 영상 게시 완료 후 알림.

## 참고
- 사이트가 알려 주는 방식이라, 사이트를 열어야 알림이 보입니다. (푸시 알림은 아님)
