## 대표님이 공유한 레퍼런스 영상 (2026-11-11)
대표님 컴퓨터에 있는 원본 파일을 기준으로 한다. (제3자 영상이라 이 저장소에는 파일을 올리지 않고 분석만 기록)

| 항목 | 내용 |
|------|------|
| 형식 | 세로 9:16, 약 **89초**(1분 29초), 오디오 있음 (끝에 약 4초 무음) |
| 주제 | **"만약 달이 사라진다면?"** 시간 순서대로 일어나는 일을 보여 주는 가상 시뮬레이션형 설명 영상 |
| 구성 | 뉴욕 코니아일랜드 해변의 밤, 사람들이 달을 구경 → 달이 사라진 순간부터 경과 시간을 세며 전개 |
| 장면 흐름 | ① 달을 보고 있는 사람들 → ② 5.7초 뒤: 달빛이 1.2초 늦게 도착(빛의 속도) → ③ 달은 없어도 마지막 달빛은 남아 있음(6배 슬로우 리플레이) → ④ 28초 뒤: 달의 중력도 사라졌지만 사람은 못 느낌 → ⑤ 39초 뒤: 파도는 그대로 → ⑥ 12시간 뒤: 만조 수위가 11~20cm 낮아짐 → ⑦ 영구적으로: 지구의 1년이 약 12시간 짧아짐 → ⑧ 2079년 뉴욕 개기일식 취소 |
| 화면 | 저폴리 3D 렌더 인물과 풍경(해변, 지구), 카메라가 움직임, 장면 전환 빠름 |
| 글자 | 좌상단 작은 라벨(REAL TIME, REPLAY, FOR GOOD), 우상단 시각/거리, 큰 수치(경과 시간·길이·거리), **하단 세리프 이탤릭 자막 2줄** |
| 톤 | 차분한 다큐 톤, 수치와 근거를 앞세움, 마지막에 반전 한 줄 |

## 이 영상에서 기억할 특징 (재사용 가능한 요소)
1. **"만약 ~라면" 가정 + 시간 경과 카운터**: 사건 이후 경과 시간이 화면에 계속 표시됨
2. **데이터 HUD**: 라벨, 시각, 큰 숫자로 근거를 보여 줌
3. **하단 세리프 이탤릭 자막**: 짧은 두 줄
4. **리플레이/슬로우 연출**: 중요한 순간을 느리게 다시 보여 줌
5. 길이가 첫 영상(30초)보다 훨씬 길다 (89초)

## 리마인드 때 대표님께 확인할 것
1. 이 영상과 **같은 주제 방식**("만약 ~라면")으로 할지, **형식만** 참고할지
2. **어떤 주제**로 할지 (채널 콘셉트는 동기부여·사람 심리·인생 교훈)
3. **길이**: 30초 쇼츠 유지 vs 60~90초
4. **그림 스타일**: 지금의 막대 인간 유지 vs 3D 실사 느낌 (3D·실사 영상은 크레딧이 훨씬 많이 듦. 장면당 수십 크레딧 예상)
5. 크레딧 상한 (첫 영상 누적 사용: 67.7, 잔액 1,642.51 기준)

## 제안 (참고용, 확정 아님)
- 막대 인간 스타일을 유지하면서 이 영상의 **경과 시간 HUD + 하단 세리프 자막** 형식만 가져오는 방법이 크레딧이 가장 적게 든다. 예: "만약 오늘 시작하지 않는다면, 1년 뒤에는?" 처럼 시간 경과를 숫자로 보여 주는 동기부여 영상.
- 저작권: 레퍼런스 영상의 장면, 문구, 수치 구성을 그대로 복제하지 않고 형식과 방식만 참고한다.

## 4번째 작업 레퍼런스 (2026-11-11 공유)
대표님 컴퓨터의 원본 파일 기준. 제3자 영상이라 이 저장소에는 올리지 않고 분석만 기록.

| 항목 | 내용 |
|------|------|
| 형식 | 세로 9:16, 약 **38초**, 오디오 있음 |
| 화면 | 검은 배경 + 흰색 막대 인간 + 가는 바닥선 (우리 채널 스타일과 거의 같음) |
| 구성 | 짧은 영어 문구 + 은유 장면을 이어 붙임 |
| 장면 | ① "Dream BIG" 거대한 블록 앞의 인물 → "Act small" 작은 계단으로 트로피 ② 의자에 앉아 고민 → 붉은 기둥 "PROBLEMS"가 생각할수록 커짐 → "Just confront it" 일어나 붉은 벽을 밂 ③ "IN A MONTH" 바위를 언덕 위로 ④ "Motivation vs Discipline" 철봉 매달리기 좌우 비교 |
| 특징 | 소품(의자, 트로피, 철봉, 바위)으로 개념을 시각화, 빨강은 "문제(벽)"에만, 문구는 화면 위/아래에 짧게, 하단에 작은 워터마크 |

**참고점:** 첫 영상의 "빨간 벽 = 넘어야 할 것" 은유와 같은 방식. 한 영상에 은유 여러 개를 이어 붙이는 구성이 새롭다.
**복제 금지:** 장면 구성, 문구, 워터마크를 그대로 쓰지 않고 방식만 참고.
