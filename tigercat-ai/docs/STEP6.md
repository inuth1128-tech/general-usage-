# 6단계: 기억 시스템 — 실행 방법 (Windows)

## 최신 파일 받고 켜기
PowerShell에서 (켜져 있으면 Ctrl+C로 먼저 끈 뒤):
```
cd ~\tigercat\general-usage-
git pull origin claude/new-session-p1cwk0
cd tigercat-ai
npm start
```
브라우저에서 http://localhost:3001 → **Ctrl+F5** (기존 데이터는 그대로 유지됩니다)

## 기억이 쌓이는 방법 (자동)
- 직원이 업무를 하면 → 메모가 남습니다.
- 대표가 **승인**하면 → "성공" 기억.
- 대표가 **반려**하면 → "실패 + 반복 금지" 기억. (그 직원은 같은 방식으로 다시 하지 않음)
- 회의가 끝나면 → 한비서가 결론을 기억. 그 회의록을 **승인**하면 결론이 **회사 전체 기억**이 됩니다.

## 대표가 직접 가르치기 ("기억" 칸)
1. 대상: **회사 전체** 또는 특정 직원
2. 종류: **규칙** / 교훈 / 실패(하지 말 것)
3. 내용을 쓰고 **기억 추가**
   예) 회사 전체 · 규칙 · "영어 문장은 12단어 이하로 쓴다"

## 기억의 작동 원리
- **규칙**과 **반복 금지**는 해당 직원이 일할 때 **항상** 떠올립니다.
- 그 밖의 기억은 이번 업무와 **관련 있는 것만** 골라서 떠올립니다. (글자 겹침 기준)
- 관련 없어도 최근 기억 2개는 함께 떠올립니다.
- 한 번에 최대 8개, 글자 수 제한이 있어 Pro 한도를 아낍니다.
- 같은 내용은 중복 저장되지 않고, 오래된 단순 메모는 400개가 넘으면 자동 정리됩니다. (규칙·교훈·반복금지는 절대 자동 삭제되지 않음)

## 확인하고 고치기
- 목록에서 **반복 금지로 / 금지 해제**, **삭제** 가능 (직원이 잘못 기억한 것을 지우세요)
- 맨 아래 **떠올리는 기억 미리보기**: 직원과 업무 내용을 넣으면, 그 직원이 지금 무엇을 떠올릴지 미리 볼 수 있습니다. (Claude 호출 없음)

## 시험해 보기
1. 회사 전체 · 규칙: `모든 영어 대본의 맨 마지막 문장은 "Stay tiger." 로 끝낸다`
2. 글이에게: `"Failure is a teacher" 주제로 30초 영어 대본을 써 줘`
3. 결과의 마지막 문장이 "Stay tiger."인지 확인
4. 시험이 끝나면 그 규칙은 **삭제**하세요.
