# 5단계: 회의와 메신저 — 실행 방법 (Windows)

## 최신 파일 받고 켜기
PowerShell에서 (켜져 있으면 Ctrl+C로 먼저 끈 뒤):
```
cd ~\tigercat\general-usage-
git pull origin claude/new-session-p1cwk0
cd tigercat-ai
npm start
```
브라우저에서 http://localhost:3001 → **Ctrl+F5**
(기존 데이터는 그대로 유지되고, 회의용 항목이 자동으로 추가됩니다.)

## 사용법
1. "회의 (메신저)" 칸에 **회의 주제**를 씁니다.
2. 참석할 직원을 **2~5명** 체크합니다. (비서실장은 자동 진행)
3. **1라운드**(빠르고 저렴) 또는 **2라운드**(깊은 토론)를 고릅니다.
4. 화면에 **예상 Claude 호출 횟수**가 나옵니다. 확인 후 **회의 열기**.
5. 메신저 창에서 직원들이 돌아가며 발언합니다. (한 명당 10~40초)
6. 대표도 중간에 한마디 할 수 있습니다. 다음 발언자부터 반영됩니다.
7. 끝나면 한비서가 **회의록**을 정리하고, "업무 기록"에 올라갑니다. 승인/반려도 가능합니다.

## Pro 한도 보호
- 호출 수 = 참석자 × 라운드 + 회의록 1회. (예: 3명 × 1라운드 = 4회)
- 오늘 남은 호출보다 많이 필요하면 회의가 시작되지 않습니다.
- 회의 중에는 다른 지시가 잠시 막힙니다. (한 번에 하나만 처리)
- 발언은 직원당 최대 4문장으로 제한합니다.
- 회의 중 오류가 나면 그 자리에서 중단되고, 지금까지의 대화는 남습니다.
