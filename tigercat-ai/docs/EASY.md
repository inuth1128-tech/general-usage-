# 더 쉽게 쓰기

## 평소에 쓰는 방법 (PowerShell 입력 없음)
1. 바탕화면의 **tigercat - start site** 를 더블클릭 → 업무사이트가 켜지고 브라우저가 열림
2. 맨 위의 **🎬 영상 제작실** 을 클릭

## 영상 제작실에서 할 수 있는 일
| 하고 싶은 일 | 누를 것 |
|--------------|---------|
| 영상 확인 | 화면 위쪽 "완성 영상"에서 바로 재생 |
| 영상 다시 만들기 | **영상 만들기** (진행 상황이 화면에 나옴, 1~3분) |
| 완성 파일이 있는 폴더 열기 | **완성 폴더 열기** |
| 장면 영상, 이미지, 음성 확인 | 화면 아래쪽에서 바로 재생 |
| 게시할 제목·설명·캡션 복사 | 각 칸의 **복사** 버튼 → 붙여넣기만 하면 됨 |
| 제가 고친 최신 버전 받기 | **최신 버전으로 업데이트** → "다시 켤까요?"에서 확인 → 5~10초 뒤 Ctrl+F5 |

## 참고
- "최신 버전으로 업데이트"로 다시 켜려면 **tigercat - start site** 로 켜 둔 상태여야 합니다. (직접 켠 경우에는 창을 닫고 아이콘으로 다시 켜기)
- **바탕화면 아이콘 처음 만들기** (한 번만): PowerShell에 아래 한 줄
```
cd ~\tigercat\general-usage-; git pull origin claude/new-session-p1cwk0; .\tigercat-ai\tools\create-desktop-shortcuts.cmd
```
- 영상 안의 **이미지·영상 클립·음성은 Claude Code 작업(크레딧 사용)** 으로 만들어집니다. 새 영상의 재료를 만드는 일은 앞으로도 저와 대화하며 진행합니다.
