# 4단계: 직원 채용 — 실행 방법 (Windows)

## 최신 파일 받고 켜기
PowerShell에서 (켜져 있으면 Ctrl+C로 먼저 끈 뒤):
```
cd ~\tigercat\general-usage-
git pull origin claude/new-session-p1cwk0
cd tigercat-ai
npm start
```
브라우저에서 http://localhost:3001 → **Ctrl+F5**

## 새로 된 것
1. **직원 지정 지시**: 지시 입력칸 옆 드롭다운에서 직원을 고릅니다 (한비서/기획이/글이/…).
2. **승인 / 반려**: 결과 아래 버튼. 반려하면 사유를 적고, 그 직원은 다음 업무부터 같은 실수를 하지 않습니다. (기억에 "반복 금지"로 저장)
3. **직원 수정**: 직원 카드의 **수정**으로 이름·직함·맡은 업무·성격을 바꿉니다.
4. **휴직/복직**: 일을 쉬게 합니다. 비서실장은 휴직할 수 없습니다.

## 시험해 보기 (순서대로)
1. 글이에게: `"Start Before You're Ready" 주제로 30초 영어 대본을 써 줘`
2. 결과가 마음에 안 들면 **반려** + 사유 입력 (예: "문장은 12단어 이하로")
3. 같은 지시를 글이에게 다시 → 사유가 반영되는지 확인

## 참고
- 직원들은 아직 글로만 일합니다. 이미지·영상은 7~8단계에서 Higgsfield와 연결합니다.
- 호출 한도(하루 20회)는 직원 모두가 합쳐서 씁니다.
