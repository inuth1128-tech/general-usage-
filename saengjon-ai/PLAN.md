## 1. 회사 구조 (조직도)

```
CEO (나)
 └─ 비서실장 "한비서"  ← 나는 이 분에게만 지시한다
      ├─ 기획팀장  "기획이"   : 상품 기획, 시장 조사, 업무 쪼개기
      ├─ 브랜드사이트 담당 "웹이"  : 생존AI 브랜드 사이트 제작·관리
      ├─ SNS 담당  "쓰레드"   : Threads 글 작성·예약·반응 분석 (브랜드 인지도)
      ├─ 상품담당  "상품이"   : 책/키링/옷/피규어 상품 등록·설명·재고
      ├─ 디자이너  "그림이" (GPT 기반) : 이미지 생성 (Claude는 이미지 생성 불가)
      ├─ 개발담당  "코딩이"   : 업무사이트·메신저 유지보수
      └─ 검수담당  "꼼꼼이"   : 결과물 최종 검수 (비서실장 보고 전 단계)
```

- 직원 이름·역할·말투·할 수 있는 일/못하는 일은 **직원 명부(DB 테이블)** 에 저장.
- 메인 두뇌 = **Claude**, 이미지 담당 1명만 **GPT** (터미널 환경에서 같은 방식으로 호출).

### 업무 흐름
1. CEO → 비서실장에게 지시 (업무사이트에서 입력)
2. 비서실장이 관련 담당자 **회의 소집** (메신저 회의방 생성)
3. 담당자들이 토론 → 비서실장이 **회의록 정리**
4. 비서실장이 담당자에게 업무 배정
5. 담당자 수행 → 검수담당 검수 → 비서실장 최종검수
6. 비서실장이 CEO에게 **보고** (업무사이트 + 메신저 알림)

## 2. 만들 것 (4개 + 기억 시스템)

| # | 이름 | 설명 | 주소(내 컴퓨터) |
|---|------|------|----------------|
| A | **생존AI 브랜드 사이트** | 브랜드 소개 + 상품(책·키링·옷·피규어) 소개/판매 | localhost:3000 |
| B | **업무 사이트 (대시보드)** | CEO가 비서실장에게 지시, 진행 과정·회의록·결과·보고 열람 | localhost:3001 |
| C | **사내 메신저** | 직원끼리 대화하며 업무 이어가기. CEO도 참관/참여 가능 | 업무사이트 안 탭 |
| D | **기억 시스템** | 직원이 했던 일·성공/실패를 기억하고 다음 작업에 반영 | DB + 서버 내부 |
| E | **Threads 연동** | SNS 글 작성·게시·반응 수집 | Threads API |

### 기억 시스템(D) 핵심 규칙
- 모든 업무가 끝나면 **업무 기록**(누가/무엇을/결과/성공·실패/배운 점) 저장.
- 직원이 일을 시작하기 전에 **과거 기록을 먼저 검색**해서 프롬프트에 포함.
- 실패로 표시된 방법은 **"하지 말 것 목록"** 에 올려 재시도 금지.
- 직원별 개인 메모 + 회사 공용 노하우 두 층으로 관리.

## 3. 기술 구성 (내 컴퓨터 안에서만)

| 영역 | 선택 | 이유 |
|------|------|------|
| 런타임 | Node.js (TypeScript) | 사이트·서버·에이전트를 한 언어로 |
| DB | PostgreSQL | 직원/업무/회의록/기억/메신저 메시지 저장 |
| 사이트 | React (Vite) + 간단한 Node API 서버 | 이 저장소 기존 구성과 동일 |
| 실시간 메신저 | WebSocket | 직원 대화 실시간 표시 |
| 에이전트 실행 | 터미널에서 Claude Code / GPT(Codex) CLI 호출 | 요청하신 "터미널 환경 연결" 방식 |
| 버전관리 | git + GitHub | 변경 이력·백업 |

## 4. 단계별 진행 (마일스톤)

| 단계 | 내용 | 결과물 | 대표가 할 일 |
|------|------|--------|-------------|
| **1. 준비** | 필요한 프로그램 설치·가입 (아래 §5) | 내 컴퓨터 준비 완료 | 가입/설치 따라하기 |
| **2. 뼈대** | DB 만들기, 서버/사이트 빈 껍데기, 직원 명부 | 업무사이트에 직원 목록 표시 | 화면 확인 |
| **3. 비서실장** | 비서실장 1명 먼저 가동 (지시→보고) | "안녕"이라고 지시하면 답 | 첫 지시 해보기 |
| **4. 직원 채용** | 담당자들 등록, 역할/이름 부여 | 조직도 완성 | 이름·역할 확인 |
| **5. 메신저+회의** | 회의 소집→토론→회의록→배정 | 업무사이트에서 과정이 보임 | 회의 지켜보기 |
| **6. 기억 시스템** | 업무 기록·검색·실패 목록 | 같은 실수 반복 안 함 | 테스트 업무 2번 |
| **7. 브랜드 사이트** | 생존AI 사이트 제작, 상품 페이지 | localhost에서 사이트 확인 | 상품 정보 제공 |
| **8. GPT 디자이너** | 이미지 생성 직원 연결 | 상품 이미지 생성 | 결과물 검수 |
| **9. Threads** | 계정 연결, 글 작성/게시 | 첫 게시물 | 승인 버튼 누르기 |
| **10. 안정화** | 비용 한도, 백업, 설명서 | 일상 운영 가능 | — |

> 원칙: 각 단계가 끝날 때마다 **대표가 눈으로 확인 → 다음 단계 승인**. 한 번에 다 만들지 않는다.

## 5. 대표님이 준비할 것 (순서대로, 하나씩 안내)

"Claude와 GPT만 설치됨, 나머지 없음"을 기준으로 가장 안전하게 작성했습니다. 이미 있는 것은 건너뜁니다.

1. **터미널 여는 법 배우기** — Windows: 시작 → "PowerShell" / Mac: Spotlight → "터미널". (터미널 = 컴퓨터에게 글자로 명령하는 창)
2. **Node.js 설치** — nodejs.org 에서 LTS 버전 다운로드 → 설치. 확인: `node -v`
3. **git 설치** — git-scm.com. 확인: `git --version` (코드 저장·되돌리기용)
4. **GitHub 가입** — github.com (이미 저장소가 있으면 완료)
5. **PostgreSQL 설치** — postgresql.org → 설치 중 입력하는 **비밀번호를 메모**. (기억·직원·업무를 저장하는 창고)
6. **Claude Code 설치/로그인** — 이미 설치됨 → 로그인 상태만 확인
7. **OpenAI(GPT) API 키 발급** — platform.openai.com (이미지 직원용, 사용량 한도 설정 필수)
8. **Threads 사용 준비** — Instagram 계정 연결된 Threads 계정 + Meta 개발자 앱 등록 (Threads API용). *이 단계는 가장 복잡하므로 9단계 때 화면 보며 하나씩 안내*
9. (판매용) **상품 판매 방식 결정** 후 필요한 가입(스마트스토어/결제대행사 등) — 질문 2 답변 후 안내

각 단계마다 "어디에서 / 무엇을 입력 / 왜 필요한지 / 성공하면 보이는 화면"을 같이 제공합니다.
